# 👻 Ghostship

**A fast-paced ghost-catching survival game where timing, reflexes, and strategy determine your rank.**

## 📌 Overview

Ghostship is a Python-based arcade game that challenges players to react quickly as ghosts appear and fall at unpredictable times.

Players must interact with falling ghosts while dealing with obstacles such as protective bubbles. As the game progresses, the difficulty increases, creating a more challenging experience.

The game features changing backgrounds, random ghost appearances, interactive bubbles, and a ranking system to make every playthrough engaging.

## 🎯 Key Features

- **Random Ghost Spawning:** Ghosts appear at random times and in random sequences.
- **Interactive Bubbles:** Some ghosts are covered by bubbles.
- **Double-Tap Mechanic:** Bubbles disappear when double-tapped.
- **Dynamic Background:** The background changes as the remaining game time decreases.
- **Ranking System:** Players receive ranks based on their performance.
- **Increasing Challenge:** The unpredictable appearance of ghosts keeps gameplay challenging.

## 🎮 Gameplay

1. Start the game.
2. Watch for ghosts appearing at unpredictable times.
3. Interact with the falling ghosts.
4. Deal with ghosts protected by bubbles.
5. Double-tap bubbles to remove them.
6. Adapt as the background changes with the remaining time.
7. Complete the game and check your final rank.

## 🏆 Ranking System

Ghostship includes a ranking system that evaluates player performance and rewards successful gameplay.
